# Knowlery Knowledge Format

**状态：Working Draft。** 本目录承载 Knowlery 2.0 最重要的长期契约：Agent 和不同工具如何理解、维护与交换同一种 Living Wiki。

从 [KNOWLEDGE-FORMAT-v0.md](./KNOWLEDGE-FORMAT-v0.md) 开始。

当前只有设计草案，**没有已批准、可宣称兼容的 Format v1**，也没有固定的字段集合和语义版本承诺。未来可在此增加 `examples/`、`schemas/` 和 `conformance/`，但应先从 Agent 实际查询与增量维护任务推导这些产物，而不是反过来让 Schema 支配 Wiki 组织。
