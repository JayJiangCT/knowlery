# GR-004 — 证据充分性导向的停止原则与可实现性边界

**日期：** 2026-11-03  
**状态：** ACCEPTED（Owner 认可 Agent 判断证据充分性 + CLI 控制资源消耗的原则，明确要求先核实技术可实现性；记录经可行性核查收窄的责任边界）  
**范围：** Knowlery 2.0 / Graph-guided Retrieval 行为原则；不代表 CLI-002 已实现或符合性测试通过  
**相关：** GR-001、GR-002、GR-003、CLI-001、A-003、A-004、F-006、F-008、PR #95

## 已接受的原则（限定责任）

1. **检索结束不以固定跳数或固定文件数作为「答案已充分」的判据**。Agent 可以根据问题意图、已读取的证据、仍待查的来源和关键矛盾，判断是否继续探索或形成回答；不能仅因为 Top-K 满额或搜索结果很多就推定答案充分。
2. **Agent 的充分性判断是模型推理，不是确定性正确性证明**。Agent 可以结束检索并给出有范围限定的答案；如果重要证据不足、存在未解决争议，或超出可检索范围，必须明确说明局限或拒绝作出确证。检索停止不消除 KF v1.0 F-008 的来源校验责任。
3. **CLI 仅负责其实际掌控范围的确定性工作**：列举与校验可观察关系和来源、返回已查/待查/失败/截断状态，限制单次请求的返回数量、文件读取、执行时间、输出大小；提供后续探索所需的稳定定位。CLI 不承诺自动判断任意问题是否「有正确答案」。
4. **跨多次调用的总预算只有在可追踪的会话/续传状态下才能强制实施**。独立 CLI 的单次调用只能强制本次调用限制；若 Agent 另开命令、跳过协定或调用其他文件工具，CLI 无法强制全局总量。可设计显式 continuation token / session ledger，但其形式尚未批准；会话元数据不得升级为知识权威状态，不违反 CLI-001。
5. **不能宣称 CLI 能精确控制 LLM 整个上下文窗口**。CLI 只能限制自己的输出并按明确的估算方法报告 Token/字节开销；实际总上下文包含系统提示、历史会话及其他工具输出，由 Agent Harness 管理。对于不可计算/不可验证的总预算，应返回 `unknown` 或局部统计，而不是伪造精确剩余 Token。
6. **资源耗尽与证据充分是不同的结束原因**。即使触发超时、深度防护或输出上限，也必须将其报告为 `budget_exhausted` / `truncated` / `incomplete` 等候选执行状态（字段名未定），不得标记为 `evidence_sufficient`。所有 Source/Claim 核查仍须遵守 KF 的规范，尤其来源 digest 与 `source-checked` 判断。

## 依赖的现有技术证据

- Obsidian 官方 CLI 帮助文档支持 `links`、`backlinks`、`read`、`search`、`eval` 等原语；提供知识链接检索的后端基础：https://obsidian.md/help/cli 。这不代表 2.0 CLI 已实现。
- PR #95：`evals/experiments/obsidian-headless/scripts/run-obsidian.ts` 已实际调用 Obsidian 搜索与 metadataCache/链接邻居，且加入 SIGKILL 超时与重试；`scripts/plan.ts` 已限制 K / MAX_TERMS。PR 的实验证明部分执行限制与数据访问路径可落地，但未验证 Agent 自主停止、会话总预算或最终证据正确率。
- CLI-001 允许短时 CLI 与会话期 MCP 进程，前提是持久 KF 文件是权威；允许可重建的派生缓存/索引。会话追踪若存在须与知识事实隔离。
- PR #95 中 C 与 E_supp 的不可回答问题正确拒答率为 0/5，说明「找到相关文件」不能视为已验证的答案充分性。

## 尚待验证：不可提前声称完成

1. 跨 CLI / MCP / 直接文件工具路径的一致性：受控调用可以返回可靠状态，绕过受控路径时不能作出全局保障。
2. 固定预算下的 History、Provenance、Synthesis 问题：Agent 能否在检索不足时明确报缺口，来源检查是否完整，错误拒答/错误确证率如何。
3. 执行时权限、超时、恢复、取消和分页续传的边界；Obsidian CLI 偶发挂起时保证有界失败。
4. Token 估算与真实 Harness 上下文的偏差，跨调用续传方案是否值得实现。
5. 「证据充分性」的操作性判据需通过实验校准；不由 CLI 伪装成真实性判定。

**不在本决策内：** 固定默认 Token 预算、具体命令名/输出 JSON 字段、会话存储结构、实施顺序或 CLI-002 最终架构批准。
