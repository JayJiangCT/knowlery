# GR-010 — CLI-002 以 search / explore / inspect 为最小检索实验范围

**日期：** 2026-11-03  
**状态：** ACCEPTED FOR PILOT（Owner 同意先以三个基础操作作为最小设计范围，依据实验结果再决定后续接口）  
**范围：** Knowlery 2.0 / CLI-002 Graph Retrieval 最小原型实验范围；**非**正式 CLI 公开接口或产品实现批准  
**相关：** A-004、CLI-001、SK-001、GR-001 ～ GR-009、F-006、F-008、PR #95

## Owner 已确认的决定

1. CLI-002 的**首轮技术原型只要求三项可组合的基础操作**，暂用工作名：
   - `search`：发现候选知识入口（包括未链接 Raw Notes），返回有界、可定位、可判断来源的候选概要；
   - `explore`：发现指定页面 / Claim 周边可解析的 KF 语义关系及 Wikilinks / Backlinks 等导航关系，默认返回关系索引而非关联全文；
   - `inspect`：按需读取指定 Claim、Record 或 Source 的可定位证据单元及可机械校验的版本/状态，并支持 GR-007 的无状态续读。
2. **Agent/Skills 编排上述操作**，而非 CLI 自行调用 LLM 识别问题意图或决定证据充分性；CLI 执行明确的确定性检索、解析、限制、读取与验证，且可批量执行已明确的子操作。GR-001～GR-009 及 KF F-008 的语义与安全边界保持适用。
3. **暂不增加高层 `retrieve` 命令**，也不因此排除未来扩展。通过真实评测观察三个基础操作是否导致调用过多、输出噪声、证据遗漏或不稳定，再决定是否有必要将常用确定性组合封装成高层便捷能力。
4. **这只是实验范围决定**。不预先接受三个工作名为稳定公开 CLI、具体 JSON Schema、默认预算、排序算法、Adapter 结构、缓存方案、正式性能承诺或发布计划；不默认修改 1.x 生产路径。

## 建议的最小技术验证（待实验，不是已得结论）

- 在只读、冻结的 Vault / Pilot Vault 快照上运行；禁止触发 Obsidian 插件的意外写入与修改真实工作 Vault。任何源数据黄金标签都要注明哪些经 Owner 复核。
- 固定问题与评价口径，至少覆盖：当前事实、决策原因、历史演进、来源追溯、跨笔记综合、未链接 Raw Note，以及不可回答 / 无关 hub 等负例。优先复用 PR #95 的难题，但不要把既有 55 题的 agent-drafted labels 当作完全人工确认的真值。
- 比较：基线关键词检索；基础操作由 Agent 规划但关闭图扩展；三操作 Agent 规划且开启意图驱动图扩展（含 KF 证据关系）；条件允许时在同一计划下对比 Obsidian 与 Headless 后端。避免把检索策略、排序、索引预热/建库时间和 backend 实现差异混为一谈。
- 观察整条 Agent 检索—回答链：必须证据覆盖与溯源、最终回答准确/合理拒答、F-008 来源检查遵守率、无链接 Raw Note 的发现率、误把导航/隐含关联当来源的频率、任务输出用量、工具调用次数、延迟、硬预算截断与无状态续读的版本失效行为。
- 测试边界：图谱 hub 引发大量邻居、同词异义、缺少 Wikilinks、Source 被修改或删除、Claim anchor 改动、Obsidian CLI 挂起/超时，以及单个证据单元大于单次输出限额。所有失败须可观察，不得被错误标成「证据已充分」。
- **通过与否的量化阈值要在实验前独立固定，并考虑人工审查与样本量**；目前未获批某个收益数字或实现完成标准。允许实验得出三操作不足、需要补充或调整的结论。

## 技术可行性依据及未验证部分

- PR #95 已证明在特定本地环境中可调用 Obsidian 的搜索、metadataCache 和链接邻居，并能做可复现的多路检索；但该实验主要是文件级召回，链接邻居扩展受 Top-K 不满时才触发，**没有证明**三操作的多轮证据获取、回答正确性或 Agent 自主停止可靠。
- KF v1.0 已定义 Claim anchor、Source 引用、证据版本、History 和 F-008 来源核查，有利于 `inspect` 的确定性实现；尚需检验异常文件、并发修改、定位失效与输出预算。
- GR-005/006 的单次硬限制、任务级软预算和完整证据单元策略仍需要代码级测试；GR-007 不承诺跨 Vault 多文件快照一致性。
- Headless 与 Obsidian 下对相同 KF 关系的兼容性是试验目标，不可直接假定已经等价。

**决策性质：** 批准首轮最小原型研究范围；不批准生产 CLI-002 实现或高层 `retrieve` 的取舍结论。
